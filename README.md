# Suhayl's Studies — Novia One Business School

NQF 7 Occupational Certificate: **Financial Markets Practitioner (FMP)**.

This repo holds my study materials, condensed summaries and workbook answers as I work through each module.

## Layout

```
Module 1/    Introduction to Financial Markets
Module 2/    Fundamentals of Economics
Module 3/    Regulation of Financial Markets
Module 4/    Equity Securities
Module 5/    Interest Bearing Securities & Bonds
Module 6/    Derivatives Markets & Alternative Investments
Module 7/    Foreign Exchange Markets
```

From Module 4 onwards each module folder uses the same sections:

| Section | Holds |
|---|---|
| `Novia one resources/` | Everything Novia One supplies as-is — study guide, class presentation, workbook, additional-resources zips |
| `Full in depth study material/` | My in-depth workbook — the full treatment of the module |
| `Summarised work book/` | The condensed summary I revise from |
| `assignment/` | The workbook / breakaway assessment: the blank `.docx` and my answers |
| `snapshots/` | Screenshots and images — class slides, lecturer's worked answers, diagrams |
| `build/` | Generator source (HTML + `pdf-house-style.css` + `build.py`) for the PDFs above |
